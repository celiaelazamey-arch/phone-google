01 / UPGRADE

اختر صورة غير قابلة للتبديل

استخدم مرجع image@sha256 من حزمة الإصدار. احتفظ بملف الأسرار وحالة النشر خارج Git. 

npm run deploy:release -- switch \
  --image ghcr.io/owner/repo@sha256:DIGEST \
  --version VERSION
02 / ROLLBACK

ارجع إلى آخر نسخة سليمة

متاح بعد تسجيل نشر سابق سليم ومتوافق مع مخطط البيانات. أول إصدار مُدار لا يملك نسخة سابقة تلقائيًا. 

npm run deploy:release -- status
npm run deploy:release -- rollback
03 / RECOVER

استعد من تبديل مُنقطع

سجل ترحيل ذري وقفل نشر يمنعان تبديلين متزامنين. أمر الاستعادة يُعيد النسخة المسجّلة ولا يخمّن حالة البيانات. 

npm run deploy:release -- recover
ⓘ

الرجوع يُبدّل كود التطبيق، ولا يسترجع البيانات المحذوفة. خذ نسخة احتياطية مستقلة من MySQL. قد يحدث انقطاع قصير أثناء استبدال الحاوية؛ ولا يوجد ضمان تشغيل بلا أعطال.
