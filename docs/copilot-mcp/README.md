## 1. لماذا طبقة وسيطة ولا يكفي ملف JSON؟

GitHub توضّح أن أدوات MCP المفعّلة لوكيل Copilot **يمكن أن تُستدعى دون موافقة مسبقة لكل استدعاء**. أي أن الإعداد وحده
ليس حدًا أمنيًا: من يملك الإعداد يملك كل أداة فيه. لذلك يوضع القيد في **شيفرة تعمل أمام الخادم**، وهي هنا
[`scripts/celia-copilot-mcp-bridge.mjs`](../../scripts/celia-copilot-mcp-bridge.mjs):

```text
Copilot ──JSON-RPC/stdio──▶ [G1 قائمة سماح] ▶ [G2 readOnlyHint] ▶ [G3 قدرات=tools] ▶ [G4 تنقية] ──▶ خادم Celia MCP
                                    │
                                    └──▶ ⛔ 12 أداة كتابة/أثر خارجي + prompts/resources: تُرفض محليًا
```

## 2. البوابات الأربع — ما تمنعه بالضبط

| البوابة | القاعدة | ما تفعله عند المخالفة |
|---|---|---|
| **G1** قائمة سماح صريحة | أربع أدوات قراءة فقط: `celia_status`، `find_skills`، `system_live_view`، `celia_secrets_status` | `tools/call` لأي أداة أخرى → خطأ `-32601` بـ`policy_blocked_tool: <name>` يحمل القائمة المسموحة. **لا يُمرَّر شيء للخادم** |
| **G2** وسوم القراءة فقط | `readOnlyHint: true` + `destructiveHint/openWorldHint/idempotentHint` مضبوطة | لا يستطيع الخادم تجاوز هذه الحقول: الوسم يُعاد كتابته في الجسر (وهي الوسوم التي تشترطها مراجعة الكود) |
| **G3** تقييد القدرات | `initialize` يُعيد `tools` فقط | `prompts/*` و`resources/*` وأي طريقة خارج القائمة → `policy_blocked_method` (لا توجد أسطح لم تُراجَع) |
| **G4** تنقية النتائج | `find_skills` مُفلترة على المسموح، وأي قيمة سرّية ← `[redacted]` | نتيجة تحمل أداة محظورة أو توكنًا لا تصل إلى المحرر أبدًا |

**عزل إضافي:** الجسر يشغّل الخادم بـ`CELIA_MCP_DISABLE_MYSQL=true` افتراضيًا، فمراجعة الكود لا تلمس قاعدة الإنتاج؛
و`CELIA_DISABLE_OLLAMA=true` كي لا ينتظر أي فحص موديلًا محليًا.

## 3. ما لم يُثبت بعد (بصراحة)

- **الاتصال الفعلي ببيئة Copilot المستضافة لم يُختبر** من هنا: لا صلاحية لتثبيت إعدادات MCP في حسابك.
- المُثبت فعلًا: الإعداد صالح ويشير إلى ملف موجود؛ والجسر يعمل أمام **خادم Celia MCP الحقيقي** عبر stdio (لا خادم اصطناعي)
  ويثبت الأدوات الأربع فقط، والرفض الفعلي لـ`whatsapp_send_text` و`prompts/list` و`resources/read`، وفلترة `find_skills`.
- تكلفة Copilot وحدود استخدامه تتبع خطة حساب GitHub، وليست جزءًا من هذا المستودع.

## 4. التركيب (أربع خطوات)

1. الملف `scripts/celia-copilot-mcp-bridge.mjs` موجود في المستودع — تأكد أنه مدموج في `main`.
2. `Settings → Copilot → MCP servers` داخل المستودع.
3. الصق محتوى `celiaos-copilot-mcp-2026.json` ثم احفظ.
4. افتح سجل Copilot: يجب أن تظهر **أربع أدوات فقط**، كل واحدة بوسم قراءة فقط. أي أداة خامسة = الإعداد يشير لملف آخر.

| حزمة النظام | **401/401** بعد إضافة الجسر · تغطية الأسطر **90.51%** |
