# بروتوكول التفوق واكتساب المستخدمين — CeliaOS (`DEC-026`)

**النطاق:** إثبات سبب انتقال المستخدم من Claude أو Manus إلى CeliaOS في مهمة ضيقة محددة (`document_data_automation`) بالاعتماد على الأدلة الموقّعة (`SHA-256`)، بوابة الفهم (`Comprehension Gate`)، وحزمة Benchmark الـ20 حالة القابلة لإعادة التشغيل.

---

## المرحلة 0: فحص الحالة المعمارية والقدرات المثبتة

- **المكونات العشرة القائمة في النواة (`src/agent/`):**
  1. `goal-contract.js` — عقد الهدف وشروط النجاح والقيود.
  2. `planner.js` — المخطط الحتمي (`PLAN_READY → WAITING_FOR_APPROVAL`).
  3. `tools.js` — سجل الأدوات المقيّد بمخطط `inputSchema` ومستوى المخاطر (`RISK`).
  4. `harness.js` — آلة حالات الخطة (`EDITED / APPROVED / REJECTED`) وحارس نزاهة الموافقة.
  5. `outbox.js` — صندوق الصادر المعاملاتي لمنع تكرار الأفعال الخارجية (`Idempotency`).
  6. `evidence.js` — سلسلة الأدلة المتسلسلة ببصمات `SHA-256`.
  7. `verifier.js` — المُتحقِّق المستقل الذي يعيد تشغيل خطوات القراءة ويفحص البوابات.
  8. `store.js` — التخزين الدائم (`MySQL 8.4` / `SQLite`) مع حذف الخيوط المحكوم.
  9. `evaluation.js` — محرك القياس والفصل الثلاثي (`executed / verified / unverified`).
  10. `automation/` — قدرة `document_data_automation` وبوابة `Comprehension Gate` وحزمة `benchmark.js` (20 حالة).

## المرحلة 2 و3: الشريحة الأولية والفرضيات التنافسية الثلاث

- **الشريحة الأولية:** المستقلون والفرق الصغيرة التي تعالج فواتير ومستندات مشتريات متكررة وتحتاج إلى نتيجة قابلة للتدقيق وإعادة التشغيل دون تكرار القيود.
- **الفرضيات الثلاث:**
  1. **فرضية الحتمية الحسابية والأدلة الموقّعة (المختارة):** يفضّل المستخدم CeliaOS في مهام الفواتير لأن كل رقم مربوط بموضعه (`row,col` / `line`) وبصمته (`file_sha256` / `report_sha256`) مع كشف 100% للأخطاء الحسابية والتكرار.
  2. **فرضية بوابة الموافقة وصندوق الصادر (`Outbox Idempotency`):** يفضّل المستخدم CeliaOS لأن إعادة تشغيل المهمة بعد انقطاع لا تكرر الإدراج في سجل المشتريات أو إرسال الرسائل.
  3. **فرضية التكلفة الصفرية والخصوصية المحلية (`NETWORK = DENY`):** يفضّل المستخدم CeliaOS لأن الفواتير الحساسة تُعالج محليًا بتكلفة `$0.00` دون رفعها إلى جلسة سحابية خارجية.
