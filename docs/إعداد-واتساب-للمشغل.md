# إعداد واتساب — خطوة المشغّل مرة واحدة

**التاريخ:** 31 أكتوبر 2026 · **الحالة:** الكود منشور ويعمل؛ تهيئة Meta ناقصة.

## التشخيص المؤكَّد من الإنتاج

آخر نشر ناجح (`Deploy (Cloudflare Edge)`، التشغيلة `41179847046`) أعطى على ملخّصه:

```
whatsapp-onboarding: configured=false
missing: Meta app, Embedded Signup configuration, Meta app secret, encryption key
```

**معنى ذلك:** كل الكود منشور ويعمل، لكن زر «اربط واتساب» سيرد `503 whatsapp_onboarding_not_configured` حتى تُضاف الإعدادات الأربعة. هذه ليست عيبًا برمجيًا، بل إعدادات لا يملكها إلا أنت.

> ملاحظة مهمة: قولك «الأسرار موجودة في أكشن» صحيح جزئيًا — هناك **18 ربطًا سريًا** مُحقنة فعلًا (مفاتيح جوجل، Gemini، Cloudflare… إلخ). لكن الأربعة الخاصة بربط واتساب **غير موجودة** بهذه الأسماء. المنصة تقرأ أسماءً محددة لا أي اسم مشابه.

## ما يجب إضافته (مرة واحدة)

في: **GitHub → Settings → Secrets and variables → Actions**

### أسرار (Secrets)

| الاسم المطلوب بالضبط | من أين تحصل عليه |
| --- | --- |
| `WHATSAPP_APP_ID` | Meta for Developers → تطبيقك → App ID (أرقام) |
| `WHATSAPP_APP_SECRET` | Meta for Developers → Settings → Basic → App Secret |
| `WHATSAPP_EMBEDDED_SIGNUP_CONFIG_ID` | Meta → Facebook Login for Business → Configurations → معرّف الإعداد |
| `TOKEN_ENCRYPTION_KEY` | مفتاح 32 بايت بصيغة base64 — لتشفير رموز العملاء في D1 |

`WHATSAPP_EMBEDDED_SIGNUP_CONFIG_ID` و`WHATSAPP_APP_ID` يقبلهما النظام كسر **أو** كمتغيّر (Variable) — أينما وضعتهما سيعمل.

### توليد مفتاح التشفير

على جهازك (لا تلصقه في المحادثة):

```sh
openssl rand -base64 32
```

انسخ الناتج إلى السر `TOKEN_ENCRYPTION_KEY`.

**تحذير:** هذا المفتاح يشفّر رموز واتساب المخزّنة. تغييره لاحقًا يجعل الاتصالات المرتبطة غير قابلة للفك، فيحتاج العملاء إعادة الربط. احتفظ به في مكان آمن.

## إعداد Meta المطلوب (مرة واحدة)

1. تطبيق Meta نوع **Business** مع منتج **WhatsApp**.
2. **Facebook Login for Business** → إعداد Embedded Signup يمنح صلاحيتَي:
   - `whatsapp_business_management`
   - `whatsapp_business_messaging`
3. في **Allowed domains** و**Valid OAuth redirect URIs** أضف:
   ```
   https://celia-phone-google.celiaelazamey.workers.dev
   ```
4. احفظ معرّف الإعداد في السر أعلاه.

## بعد الإضافة

شغّل `Deploy (Cloudflare Edge)` من تبويب Actions (Run workflow)، أو ادفع أي تغيير إلى `main`. ثم اقرأ ملخّص التشغيلة:

- `whatsapp-onboarding: configured=true` ← جاهز، يستطيع أي مستخدم الربط.
- ما زال `configured=false` ← الاسم غير مطابق تمامًا أو القيمة غير صالحة؛ التنبيه يسمّي الناقص.

## ما يفعله المستخدم العادي بعدها

لا شيء مما سبق يراه المستخدم. رحلته:

1. يفتح `https://celia-phone-google.celiaelazamey.workers.dev/whatsapp`
2. ينشئ حسابًا بالبريد وكلمة المرور
3. يضغط **«اربط واتساب»** → نافذة Meta → يختار رقمه → يوافق
4. تتولى سيليا الباقي، ثم **«أرسل رسالة اختبار»** والوارد

## حدود معلنة

- لا يوجد تحقق بريد ولا استعادة كلمة مرور في هذه الشريحة.
- الرد الآلي للمستخدمين العاديين مطفأ عمدًا.
- **لم تُنفَّذ رحلة ربط حقيقية بعد**؛ `whatsappLiveConnectionVerified` يبقى `false` حتى تُنفَّذ وتُوثَّق.
