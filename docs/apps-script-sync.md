# مزامنة Google Apps Script إلى المستودع — `apps-script:sync`

> **GOOG-006 / DEC-142.** الأداة تسحب الكود من نسخ clasp المحلية إلى `apps-script/` داخل المستودع، **بمعاينة قبل التطبيق**. لا تتصل بـ Google ولا تفتح أي منفذ شبكة؛ خطوات clasp نفسها تتم على جهاز المالك بحسابه.

## الصورة الكاملة

```
جهاز المالك                          هذا المستودع
─────────────                        ─────────────
clasp login (مرة واحدة)
clasp clone <SCRIPT_ID>  ──►  ~/celia-apps/<project>/
                                   │
                                   ▼  npm run apps-script:sync -- --pull        ← معاينة فقط
                                   ▼  npm run apps-script:sync -- --pull --accept ← تطبيق بعد المراجعة
                              apps-script/<project>/
```

## خطوات المالك (على جهازك، بحسابك — لا ينفذها الوكيل)

```bash
# 1) تسجيل الدخول بحسابك، مرة واحدة
npx @google/clasp login

# 2) مجلد النسخ المحلية
mkdir -p ~/celia-apps
cd ~/celia-apps

# 3) استنساخ المشروع — الجزء الطويل بعد /projects/ من رابط مشروعك في script.google.com
npx @google/clasp clone <SCRIPT_ID>
# إن كان عندك أكثر من مشروع، استنسخ كل واحد في مجلد فرعي باسمه:
#   mkdir ~/celia-apps/inventory && cd ~/celia-apps/inventory && npx @google/clasp clone <ID>
```

ملاحظات على بنية `~/celia-apps`:

- **مشروع واحد مباشرة في الجذر:** إن نفّذت `clasp clone` داخل `~/celia-apps` نفسها فسيصبح الجذر نفسه مشروعًا واحدًا باسم المجلد — الأداة تدعم ذلك.
- **عدة مشاريع:** كل مجلد فرعي مباشر يحتوي `.clasp.json` يُعامل مشروعًا مستقلًا. المجلدات بلا `.clasp.json` تُتجاهل.
- يمكن تغيير المصدر بـ`--source <dir>` أو متغير البيئة `CELIA_APPS_SCRIPTS_DIR` (مسار فقط، ليس سرًا).

## خطوات المستودع (تعمل الآن)

```bash
cd /path/to/phone-google

# 4) شوف الفرق الأول — لا يكتب شيئًا
npm run apps-script:sync -- --pull

# 5) طبّق بعد ما تراجعه بس
npm run apps-script:sync -- --pull --accept
```

خيارات إضافية: `--project <name>` لمشروع واحد · `--dest <dir>` لتغيير الوجهة · `--json` لتقرير JSON وحيد قابل للتحليل · `--help`.

### رموز الخروج

| الرمز | المعنى |
|---|---|
| 0 | متزامن، أو طُبّق بعد `--accept` وتحققت المطابقة |
| 1 | فروق بانتظار المراجعة (معاينة) — راجعها ثم طبّق |
| 2 | مدخل خاطئ أو رفض أمان — لا شيء كُتب للمشاريع المرفوضة/المحجوبة |

## بوابات الأمان (لماذا الأداة متشددة)

1. **المعاينة أولًا:** بلا `--accept` لا تُكتب أي بايت. الحذوفات تُعرض في المعاينة ولا تُنفَّذ إلا مع `--accept`.
2. **ملفات الاعتماد لا تُنسخ أبدًا:** `.clasprc.json` و`.clasprc.*.json` و`.env*` و`credentials.json` و`token.json` و`client_secret*.json` و`service-account*.json` و`*.pem|*.p12|*.key` و`.DS_Store` — تُذكر بالاسم في التقرير وتُستبعد. ووجودها في الوجهة لا يجعلها مرشحة للحذف (تُترك وتُذكر لتحذفها يدويًا). `.gitignore` يحرس `.clasprc*` أيضًا.
3. **فحص الأسرار على المحتوى:** كل ملف مصدري يفحصه `findSecret` المشترك (`src/knowledge/validate.js`). أي إصابة ترفض المشروع كله **وتمنع التطبيق عن كل المشاريع** (الكل أو لا شيء) — التقرير يذكر المسار ونوع السر، لا قيمته أبدًا، ورقعة الملف المصاب تُكتم.
4. **الروابط الرمزية مرفوضة** على الجانبين (رابط في الوجهة قد يعيد توجيه الكتابة خارج المشروع)، والملفات الثنائية مرفوضة — مشاريع Apps Script نصية.
5. **حارس الوجهة:** يُرفض جذر المستودع وأصوله والمجلدات المحمية (`.git`، `node_modules`، `src`، `scripts`، `test`). كل كتابة تنحصر داخل `<dest>/<project>/` وتتم بـtmp+rename ذري، ثم تُعاد لقطة تحقق — لا يُكتب «applied» إن لم تتطابق الوجهة فعلًا.
6. **مشاريع الوجهة الغائبة عن المصدر تُذكر ولا تُحذف** (`missingFromSource`) — الحذف على مستوى الملفات داخل المشاريع المتطابقة فقط.
7. **سحب فقط:** `--push` مرفوض برسالة مسماة. الدفع إلى Google قرار مالك يدوي عبر `clasp push` من مجلد النسخة المحلية.

## تحذير المستودع العام

هذا المستودع **عام**. أي ملف يدخل `apps-script/` يصبح منشورًا للعالم بعد الدفع. زامن فقط الكود الذي تقصد نشره، وراجع كل رقعة في المعاينة قبل `--accept`. الأداة لا تفهم «نية النشر» بدلًا عنك؛ فحص الأسرار شبكة أمان لا بديل عن المراجعة.

## الدفع إلى Google (خارج نطاق الأداة)

إن عدّلت الكود داخل المستودع وأردت رفعه إلى Apps Script، فالطريق المعاكس يدوي بقرار المالك: انسخ التغييرات إلى مجلد النسخة المحلية ثم `npx @google/clasp push` من هناك. لا توجد أتمتة لهذا الاتجاه في الأداة (DEC-142).
