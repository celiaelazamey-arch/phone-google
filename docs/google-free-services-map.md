# خريطة ربط CeliaOS بخدمات Google المجانية

**التاريخ:** 27 أكتوبر 2026 · **الحالة:** وثيقة تصميم وقرار. الواجهة المقابلة:
[`public/google-map.html`](../public/google-map.html). التمييز هنا بين **منفّذ برمجيًا في المستودع**
و**مخطط** و**قرار مطلوب من المالك** — لا شيء هنا يُعدّ ربطًا حيًا متحققًا.

## 1. لماذا خدمات مجانية متعددة بدل خدمة واحدة

كل خدمة تملك دورًا واحدًا وحدًّا وثمن خصوصية مختلفًا. الجدولة والتفكير والتخزين والنشر طبقات منفصلة،
فسقوط إحداها أو تغيّر شروطها لا يجر الباقي.

| الخدمة | الدور في CeliaOS | الحالة | الحد/الثمن |
|---|---|---|---|
| GitHub + Pages | كود وواجهات ثابتة بHTTPS | منفّذ برمجيًا؛ تفعيل Pages بضغطة مالك | Pages ملفات فقط، بلا أسرار |
| Cloudflare Worker | جسر `celia-cron-bridge` حامل السرّين | منفّذ برمجيًا، غير منشور | 100 ألف طلب/يوم |
| cron-job.org | نداءات HTTPS مجدولة | منفّذ برمجيًا عبر الجسر، غير منشور | 5 طلبات/ثانية؛ الحصة اليومية مراجعة من Console |
| Google Calendar/Gmail/Drive/People | OAuth بأربع واجهات وتوكنات مشفرة AES-256-GCM | منفّذ برمجيًا (GOOG-001/002)؛ ربط حي غير مختبر | نطاقات ضيقة وتحقق من بريد المالك |
| Gemini API (مجاني) | تخطيط وتلخيص واقتراح أدوات | الكود موجود؛ **قرار الشروط مطلوب** (AI-002) | حصص متغيرة؛ بيانات الفئة المجانية قد تُستخدم لتحسين المنتجات وتراجَع بشريًا |
| Ollama محلي | بديل ذكاء بلا مشاركة بيانات | مخطط (`src/ollama.js` موجود) | صفر تكلفة سحابية، تكلفة جهاز |
| Google Drive | نسخ مشفرة وملفات معرفة/KB | مخطط (KB-004، DATA-001) | سعة مشتركة مع الحساب؛ ليس مكان قاعدة تشغيلية |
| Google Sheets | سجل تشغيل خفيف قابل للعرض | مخطط | حصص API كافية للاستخدام الشخصي |
| Apps Script | أتمتة خفيفة بلا خادم | مخطط | حصص يومية، ليس خادمًا دائمًا |
| Google Colab | ورشة تطوير وتجارب Python | مخطط | جلسات تنقطع، موارد غير مضمونة |

## 2. مسار المهمة الواحدة عبر الطبقات

1. **cron-job.org** يطلق نداء HTTPS في الموعد.
2. **Worker (أو Apps Script للمهام البسيطة)** يتحقق من الرمز والصلاحيات.
3. **CeliaOS + Gemini** يحلل النتيجة ويتخذ الإجراء المسموح به فقط.
4. **Sheets / Drive** يسجّلان النتيجة ويحفظان النسخة.

## 3. ترتيب التنفيذ الموصى به

1. **GitHub + Pages** — الكود والواجهة الثابتة أولًا (موجودًا)، وتفعيل Pages مرة واحدة من Settings.
2. **Drive + Sheets** — ذاكرة ونسخ وسجل تشغيل قبل أي أتمتة.
3. **Gemini المجاني** — بعد قرار شروط الخصوصية الصريح، ولبيانات غير حساسة في البداية فقط.
4. **جسر cron-job.org** — نشر Worker بسرّيه ثم ربط لوحة [`/cron`](../public/cron.html).
5. **Apps Script** — عند ظهور أتمتة خفيفة لا تستحق خادمًا.

## 4. حواجز قرار لا تُتجاوز تلقائيًا

- **لا أسرار على Pages إطلاقًا.** المفاتيح في Worker secrets أو خادم سيليا. الواجهات الثابتة تُفحص في CI
  ضد أي تسريب قيم أسرار (`pages.yml`).
- **قرار Gemini قبل البيانات الحقيقية.** شروط الفئة المجانية تسمح باستخدام المحتوى لتحسين المنتجات وقد يراجعه بشر؛
  لا رسائل عملاء ولا مفاتيح ولا بيانات حساسة قبل موافقة المالك الصريحة. البديل المحلي Ollama موثق بجانبه.
- **سياسة الاحتفاظ والحذف** تُكتب وتُعتمد قبل أول رسالة عميل حقيقية، وتشمل السجلات والنسخ والمهام المجدولة.
- **أضيق نطاق صلاحية.** ربط Google بنطاقات محددة (`calendar.events` + `openid/email`) بلا توسيع بلا حاجة موثقة.

## 5. ما لا تعدّه هذه الخريطة

- لا تُعدّ الخدمة «مربوطة» بمجرد ظهورها هنا؛ الدليل الحي الوحيد هو اختبار ناجح على حساب المالك ورابط منشور.
- الحدود المجانية لقطة من وقت الكتابة وقد تتغير؛ راجع وثائق كل مزوّد قبل بناء التزامات تشغيلية عليها.
- الخدمات المجانية لا تشتري SLA ولا توافرًا عاليًا؛ أي ضمان تشغيلي يحتاج خطة مدفوعة موثقة بقرار منفصل.
