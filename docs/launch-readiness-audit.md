## بند التحقق الإضافي المعتمد تصميمًا: `/readyz` (`DEC-131`)

التصميم معتمد: العام يقتصر على `{"ok":true,"ready":true}` والتفاصيل خلف مصادقة. **التنفيذ مؤجل** لرفع التجميد بجلسة معتمدة، مع ترحيل فحوص `verify-live --mode edge` (تقرأ التفاصيل العامة حاليًا — `verify-live.mjs:185-198`) إلى النقطة الموثقة حتى لا يكسر التقليم فحوص النشر.

## قائمة المالك — بالترتيب (كلٌّ بدقائق إلى ساعة)

1. **GitHub**: Settings → General → Pull Requests → **تعطيل Allow auto-merge** (درس `#154`) · Rules → ruleset [`26270171`](https://github.com/celiaelazamey-arch/phone-google/rules/26270171): إضافة قاعدة pull_request بمراجعة ≥1 (بقرار سياسة التجاوز: bypass/مراجع ثانٍ) + Required status checks = `Celia quality & resilience`.
2. **Google Console**: Publishing status → In production (أو Test users للمسار المحدود أولًا) + شاشة موافقة خارجية → ثم افتح `/auth/google/diagnostics` على الحافة وتحقق `google.accepted=true`.
3. **Meta**: إكمال الرقم وبيانات النشاط وwebhooks + إنشاء حساب اختبار واتساب.
4. **Reality**: Actions → *Service reality audit* → Run workflow → `live_only=true`.
5. **الرحلتان الحيّتان** (شرطا الإطلاق الحاسمان): الرحلة الكاملة بجوجل ثم ربط واتساب برسالة إرسال **واستقبال**.
6. **عند النجاح**: تجربة محدودة بإصدارات تدريجية + مراقبة فواتير Meta والأخطاء → قرار الفتح العام.
