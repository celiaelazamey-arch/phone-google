# بروتوكول البوابات الصارمة لتوليد الكود (Milestone-Gated Code Generation)

وُثّق واعتُمد في هذه الجلسة بناءً على توجيه المالك. الهدف: **يُمنع الانتقال من المهمة $Task_N$ إلى $Task_{N+1}$ إلا بعد تحقّق ≥ 90%** في معايير قبول المهمة الحالية.

## 1. التجزئة الذرية (Decomposition)

كل مهمة صغيرة بما يكفي لتُختبر وحدها، ولها **مدخلات / مخرجات / معيار بوابة** معلن مسبقًا. لا تُدمج مهمتان في خطوة واحدة.

## 2. قائمة تحقق القبول (Acceptance Criteria)

لكل مهمة تُقاس الدرجات من 100:

| المعيار | الوزن | كيف يُقاس فعليًا |
|---|---:|---|
| صحة المنطق البرمجي | 30 | اختبارات وحدة بمزودات محاكاة تغطي المسار السعيد + الفشل + الحدود |
| سلامة الصياغة والتكامل | 20 | `npm run check` + `npm test` كاملين بلا فشل |
| حماية الأسرار والتكلفة | 20 | لا مفتاح في URL/سجل/استجابة؛ فحوص غير مستهلكة للحصة؛ واجهة sandbox معزولة |
| التوافق مع الكود القائم | 15 | عدم كسر الأدوات/الاختبارات السابقة، وتحديث العدّادات المتأثرة |
| قابلية الملاحظة والتوثيق | 15 | حالة قابلة للقراءة عبر `status`/annotation + توثيق في README |

**قاعدة البوابة:**
- `score ≥ 90` → ✅ يُسمح بالانتقال الفوري وتُسجَّل النتيجة في سجل البوابات أدناه.
- `score < 90` → ⛔ يُمنع الانتقال؛ تُحدَّد الثغرة، يُعاد التصحيح، ويُعاد التقييم في حلقة مغلقة.

## 3. دورة التنفيذ

```
[توليد كود المهمة N] → [فحص وتقييم ذاتي]
                            │
              ┌─────────────┴─────────────┐
              ▼                           ▼
      [النتيجة < 90%]              [النتيجة ≥ 90%]
              │                           │
   [تحديد الثغرة + تصحيح]        [توثيق النجاح + أرشفة]
              │                           │
              └──────────► [الانتقال للمهمة N+1]
```

### ملخص حالة المراحل

- **المرحلة 1** (الموجّه الذكي) و**المرحلة 4** (لوحة الأسرار السبعة): مكتملتان ومُتحقق منهما في CI.
- **المرحلة 2** (محرك الصوت) و**المرحلة 3** (جسر Figma): مكتملتان من ناحية الكود والاختبارات بمزودات محاكاة؛ التكامل الحي **معلّق على T0**.
- لا يمكن إعلان اكتمال المشروع بنسبة 100% قبل تحديث الأسرار الثلاثة وإعادة قياس T0 ≥ 90%.

> **ملاحظة تبعية:** T0 بوابة *جاهزية حية* مستقلة عن بوابات *صحة الكود*. مهام الكود T1–T7 تُبنى وتُختبر بمزودات محاكاة (وهذا معيار قبولها)، لكن **التشغيل الحي** لـ T1/T4 يظل معلقًا حتى تُغلق T0. لا يُسمح أبدًا بالادّعاء أن مفتاحًا مرفوضًا يعمل.
