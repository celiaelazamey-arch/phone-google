# وسيط الخروج (egress proxy) — M-C / C1

> **الحالة:** الشريحة **C1-a** منفَّذة ومختبَرة (الوسيط + سياسة per-run + التدقيق). **C1-b** (ربط الأدوات به) لم تُنفَّذ.
> **القرار:** [DEC-059](continuity/DECISIONS.md) · **الاختبارات:** `test/agent-egress-proxy.test.js` (EP-01..EP-13).

## 1. لماذا هذا المكوّن هو الأخطر في الخطة

حتى اليوم، سياسة العزل في `src/agent/sandbox-policy.js` ترفض أي شبكة **بالكود**:

```js
if (network.mode !== 'deny') throw new Error('sandbox_network_must_default_deny');
if (!Array.isArray(network.allowlist) || network.allowlist.length !== 0) {
  throw new Error('sandbox_egress_allowlist_backend_unavailable');
}
```

هذا يعني أن أول سطر يفتح الشبكة هو أيضًا أول سطر يفتح ثغرة. لذلك بُني **الباب قبل المفتاح**: لا وجود لأي فتح في العزل، والوسيط وحده هو ما يمكن أن يفتح لاحقًا — وهو مبنيّ ومختبَر أولًا.

## 2. نموذج التهديد وترتيب الإنفاذ

| القاعدة | كيف تُنفَّذ في الكود | كيف تُقاس |
|---|---|---|
| **لا منحة = لا حزمة** | `resolveGrant` يرفض 407 قبل تحليل الهدف أصلًا | EP-02، EP-10 |
| **القرار قبل DNS** | مطابقة نصية للـhost ضد قائمة التشغيل؛ المحجوب لا يصل `http.request`/`net.connect` | EP-04 (اسم لا يُحل + IP غير مدرج = 403 فوري، وصفر اتصال بالخادم الشرير) |
| **قائمة لكل تشغيل** | `issueGrant({ runId, allowlist })` → رمز معتم 64-hex؛ لا قائمة مشتركة بين التشغيلات | EP-02، EP-10 |
| **حدود واضحة** | `host` أو `host:port` أو `*.suffix` — والبدل لا يطابق الأصل ولا `evilexample.com` | EP-01 |
| **لا محارف ملتبسة** | IDN يُرفض بدل تطبيعه (لا `xn--` ضمني، لا تشابه بصري) | EP-01 |
| **كل قرار في الأدلة** | `onEvent` لكل قرار: سماح أو منع، مع الدومين والمنفذ والمساري والحجم والحالة والمدة | EP-03، EP-09 |
| **لا أسرار في السجل** | لا ترويسات ولا query strings ولا رمز منحة | EP-08 |
| **سقوف تقطع** | تجاوز حجم الطلب/الرد أو المهلة أو سقف الأنفاق يقطع الدفق ويُسجَّل `blocked` | EP-06، EP-07 |
| **الافتراضي مغلق** | `createEgressAllowlist({ hosts: [] })` = منع كل شيء؛ `*` مرفوض بالبناء | EP-01، EP-11 |

## 3. السطح

```js
import { createEgressProxy, createEgressAllowlist, createEvidenceEgressSink } from './src/agent/egress-proxy.js';

const proxy = createEgressProxy({ onEvent: createEvidenceEgressSink({ store }) });
const { url } = await proxy.listen({ port: 0 });          // 127.0.0.1 فقط
const grant = proxy.issueGrant({ runId, allowlist: ['api.example.com:443', '*.cdn.example.com'], ttlMs: 300_000 });
// داخل التشغيل: HTTPS_PROXY=url + Proxy-Authorization: Bearer <grant.token>
```

- **HTTP:** صيغة absolute-form (`GET http://host/path`) مع تمرير الترويسات السليمة وحذف hop-by-hop.
- **HTTPS:** `CONNECT host:443` وحده؛ لا فك تشفير ولا شهادة جذرية مزروعة.
- `revokeRun(runId)` / `revokeGrant(token)` / `activeGrants()` / `events()` / `stats()`.
- السقوف الافتراضية: 1MiB طلب، 8MiB رد، 15s مهلة، 8 أنفاق لكل منحة — قابلة للضبط عند الإنشاء فقط.

## 4. ما لم يُنفَّذ (بصراحة)

1. **لا أداة ويب بعد.** `web.fetch`/`web.search` هما C2، ولم تُسجَّل أي أداة جديدة في هذه الشريحة.
2. **العزل ما زال `deny` حرفيًا.** EP-11 يحرس ذلك: `network.allowlist` ما زال مرفوضًا في `sandbox-policy.js`.
3. **لا ربط في `createAgentHost`.** الوسيط وحدة قابلة للتركيب بلا مستهلك بعد؛ إضافته إلى الإقلاع بلا مستهلك كانت ستنتج سطحًا ميتًا، فتُرك الربط لـC1-b.
4. **لا قياس حي على إنترنت حقيقي.** كل الاختبارات على مقابس محلية (خادم وجهة وهمي + خادم «شرير» يجب ألا يُلمس). أي اتصال خارجي قرار نشر منفصل.

## 5. القرار المعماري المقترح لـC1-b (انحراف مُعلن عن نص الخطة)

نص الخطة يقول «عندها فقط تُفتح `network.allowlist`». الأنفع والأقوى — وقد يكون ما نفعله فعلًا — أن **تبقى الشبكة في العزل `deny` إلى الأبد**، وأن تُنفَّذ أدوات الويب **على المضيف عبر الوسيط** (كما تعمل بقية الأدوات)، فيصبح العزل بلا شبكة أصلًا وليس «بشبكة مسموحة».

مزايا ذلك:
- لا حاجة لبناء veth/slirp داخل namespace المهمة ولا لصلاحيات `CAP_NET_ADMIN` وقت التشغيل.
- كل طلب يمر بمنحة تشغيل واحدة وقائمة واحدة وسجل واحد — لا مسار شبكة ثانٍ يُدقَّق بشكل مختلف.
- يقلّل سطح الهجوم: لو انكسر العزل، لا شبكة هناك ليُستغلّ.

العيب الوحيد: جلب الصفحات يتم على المضيف لا داخل العزل، أي أن صفحة خبيثة تُعالَج في عملية المضيف — وهو ما تحكمه C5 (فحص الحقن قبل أن يرى المخطط أي نص) والسقوف والحجم. هذا القرار يُحسم في DEC لاحق قبل C2، ولا يُفترض اليوم.
