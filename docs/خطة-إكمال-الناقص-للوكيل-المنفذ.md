### المرحلة 1 — استقرار CI واستدعاء Gemini (أولوية قصوى) 🎯 للوكيل المنفّذ

**الهدف:** منع تكرار فشل CI العابر بعد تعليق 5 دقائق، مع بقاء الفحوص المحلية صارمة.

**1.1 — مهلة زمنية لاستدعاء Gemini** في `src/gemini.js`:

```js
export async function generateWhatsAppReply({ config, customerMessage, timeoutMs = 20_000 }) {
  const { apiKey, model, businessContext } = config.gemini;
  if (!apiKey) throw new Error('Gemini API is not configured');
  const endpoint = `https://generativelanguage.googleapis.com/v1beta/models/${encodeURIComponent(model)}:generateContent`;
  const response = await fetch(endpoint, {
    method: 'POST',
    headers: { 'content-type': 'application/json', 'x-goog-api-key': apiKey },
    signal: AbortSignal.timeout(timeoutMs),          // ← الجديد: يمنع التعليق
    body: JSON.stringify({ /* ... كما هو دون تغيير ... */ })
  });
  // ... باقي الدالة كما هي
}
```

- اربط `timeoutMs` بـ `config.gemini.timeoutMs` إن أردت ضبطه بـ `GEMINI_TIMEOUT_MS` (افتراضي 20 ثانية).
- في `src/ollama.js` `generateCeliaReply()`: وسّع شرط النماذج البديلة ليشمل أخطاء الشبكة: `/\((404|429|503)\)|timed out|abort/i`.
- اختبار جديد في `test/gemini.test.js`:

```js
test('Gemini request aborts instead of hanging forever', async () => {
  const previousFetch = globalThis.fetch;
  globalThis.fetch = (_url, options) => new Promise((_resolve, reject) => {
    options.signal.addEventListener('abort', () => reject(new Error('aborted by timeout')), { once: true });
  });
  try {
    await assert.rejects(
      generateWhatsAppReply({
        config: { gemini: { apiKey: 'k', model: 'm', businessContext: '' } },
        customerMessage: 'مرحبا', timeoutMs: 30
      }),
      /aborted|timed out/i
    );
  } finally { globalThis.fetch = previousFetch; }
});
```

**1.2 — حماية سير العمل** في `.github/workflows/celia-mcp.yml`:

```yaml
concurrency:                                   # على مستوى الـworkflow
  group: celia-mcp-${{ github.ref }}
  cancel-in-progress: true

jobs:
  verify-celia-mcp:
    timeout-minutes: 12                        # ← يمنع أي تعليق مفتوح
```

- أضف `signal: AbortSignal.timeout(30_000)` إلى كل `fetch` داخل سكربت التحقق (بما فيها فحص الـ401).
- لفّ «التحقق الحي من Gemini» بـ `try/catch`، وعند الفشل الخارجي سجّل `::warning::` مع وسم واضح في `GITHUB_STEP_SUMMARY` بدل إسقاط المهمة. **تبقى صارمة:** فحوص 401، `initialize`، `tools/list` (12 أداة)، `celia_status`.
- أضف مفتاح تشديد اختياري: `REQUIRE_GEMINI_LIVE: ${{ vars.REQUIRE_GEMINI_LIVE || 'false' }}`؛ إن كان `true` يُعاد رمي الخطأ. (القرار في §4.)

**أوامر القبول:**

```bash

npm run build:pages && npm run celia:mcp:verify
git add -A && git commit -m "fix(ci,gemini): bounded timeouts + resilient external verification"
git push origin arena/af6275d2-phone-google
# افتح PR من الفرع إلى main، انتظر CI، لا تدمج قبل الأخضر، ثم شغّل CI مرة ثانية للتأكد من عدم التذبذب
```
