الربط الكامل المتكامل
لمساعد الهاتف + Google

واجهة API آمنة تربط Google OAuth مع WhatsApp Cloud API وتخزّن الحالة والرسائل في MySQL، مع ردود Gemini الاختيارية المعلّقة على موافقات صريحة. كل شيء يعمل مجانًا: وضع تجريبي كامل بلا حسابات، CI مجاني، وثائق منشورة على GitHub Pages.

Node.js 20+AES-256-GCMHMAC-SHA256OAuth state وحيد الاستخدام21 اختبارًاتكلفة صفر

▶ شغّل النسخة التفاعلية الآن (تعمل على هاتفك بلا سيرفر)

الرابط أعلاه صفحة مستقلة تمامًا: تُشفّر الرموز بـ AES-256-GCM وتحسب HMAC-SHA256 فعليًا داخل المتصفح. تفتح من أي متصفح أو هاتف، حتى دون اتصال بالإنترنت بعد تحميلها.

ابدأ خلال دقيقتين

npm ci
npm run demo
# افتح http://localhost:3000

لا حساب Google، لا تطبيق Meta، لا مفتاح Gemini، لا MySQL، ولا اتصال خارجي. نفس مسارات الإنتاج بمزوّدين وهميين داخل العملية.

محليًا مع MySQL حقيقي

npm run setup
docker compose up -d mysql
npm run db:init
npm test && npm start

كيف يتدفّق الربط

Google OAuth ←→ رموز مشفّرة في MySQL
↓ Gmail / Drive / Calendar / Contacts (قراءة + موعد)
WhatsApp Webhook ← HMAC-SHA256 + منع التكرار
↓ موافقة WhatsApp + موافقة AI + نافذة 24 ساعة
Gemini ←→ رد قصير آمن ←→ إرسال فردي عبر Graph API

لا بث جماعي، لا قوالب، لا مرفقات بريد، لا إرسال بريد، ولا معالجة دفع أو بيانات حساسة.

الأمان مُطبّق في الكود

  • تشفير الرموز بـ AES-256-GCM وstate م hashed لمدة 10 دقائق.
  • تحقّق التوقيع على البايتات الخام قبل تحليل JSON.
  • منع الإرسال دون موافقة موثّقة، وخارج نافذة 24 ساعة.
  • موافقة منفصلة aiOptedIn قبل إرسال نص العميل إلى Gemini.
  • Helmet، حدود الأحجام، E.164، UTC، إيقاف تشغيلي نظيف.
  • الوضع التجريبي يُرفض في NODE_ENV=production.
