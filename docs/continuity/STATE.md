## الفحوص المنفذة فعليًا عند إعداد الخطة

بيئة محلية: Node `22.22.3` / npm `10.9.8`.

| الأمر | النتيجة |
|---|---|
| `npm ci --no-fund` | ناجح؛ audit كامل صفر ثغرات معروفة، مع تحذيرات deprecation تبقى للمراجعة |
| `npm run check` | ناجح، 40 ملف JavaScript |
| `npm run release:check` | ناجح؛ 0.2.0 / السابق 0.1.0 / schema=1 |
| `npm test` | 59/59 ناجحة، صفر تجاوزات |
| `CELIA_MCP_DISABLE_MYSQL=true CELIA_DISABLE_OLLAMA=true npm run celia:mcp:verify` | ناجح، 12 أداة، لم يُختبر AI حيّ |
| `npm run build:pages` | ناجح، 5 صفحات و12 أداة |
| `npm audit --omit=dev --audit-level=moderate` | صفر ثغرات معروفة وقت الفحص |
| فحص توثيق محلي لمرة واحدة | 14 ملف Markdown و49 رابطًا محليًا سليمًا و35 معرف مهمة؛ لا تبعيات دائرية أو مراجع مهام مفقودة |
| مقارنة نطاق Git و`git diff --check` | لا تغيير في مسارات التشغيل/الاعتماديات/SQL/الإصدارات، ولا أخطاء whitespace؛ النص التاريخي لم يُحذف |

المتصفح وDocker وMySQL الحقيقية وrestore/rollback التشغيلي لم تُشغل محليًا ضمن إعداد هذه الخطة. حزمة المتصفح الموجودة تضم 12 حالة؛ لا تنقل نتيجتها من جلسة قديمة كأنها إعادة تشغيل الآن. CI المتغير يُراجع على commit وPR الحاليين من GitHub، وليس من وصف ثابت هنا.

النتائج أعلاه فحوص خط الأساس؛ تغييرات هذه الجلسة لا تمس أي JavaScript أو dependency أو SQL أو إعداد تشغيل أو manifest إصدار. ملفات `dist/` و`node_modules/` محلية/متجاهلة وليست تسليمًا داخل Git.
