# تسليم جلسة — YYYY-MM-DD — عنوان قصير

> انسخ القالب باسم فريد داخل `docs/continuity/sessions/`. لا تستبدل سجل جلسة قديمة.

## المهمة والتفويض

- طلب المستخدم والمتطلبات الجديدة المهمة:
- معرفات BACKLOG ومعايير القبول:
- النطاق المسموح؛ ما يحتاج موافقة مستقلة:

## واقع البداية

- الفرع الذي أثبتته البيئة وGit:
- baseline commit وإصدار التطبيق:
- worktree المستخدم الذي وجب الحفاظ عليه:
- حالة PR/CI/النشر إن تحققت، مع الرابط والتاريخ، أو «لم يُتحقق»:

## ما تغير فعليًا

- الملفات أو الوحدات والغرض:
- قرارات DEC الجديدة/المستبدلة:
- ما بقي مجرد اقتراح ولم ينفذ:

## الفحوص

| الأمر/الفحص | commit/البيئة | النتيجة أو سبب عدم التشغيل |
|---|---|---|
| اكتب الأمر الفعلي | اكتب المرجع | لا تنقل نجاحًا من جلسة سابقة |

## الحفظ والتسليم

- commit/مرجع التغيير، وحالة الدفع الفعلية:
- رابط PR وCI إن توفر؛ لا تعتبر artifact أو commit محليًا نشرًا:
- حالة الإنتاج والبيانات والأسرار؛ اذكر صراحة العمليات الخطرة التي لم تنفذ:
- أي نتيجة خارجية غير معروفة، بلا إعادة إرسال:

## الاستئناف

- العوائق والمعلومات المطلوبة دون أسرار:
- الخطوة التالية بالضبط ومعرفها وأول فحص آمن:
- تأكيد تحديث STATE والصفوف المتأثرة في BACKLOG والقرارات:
