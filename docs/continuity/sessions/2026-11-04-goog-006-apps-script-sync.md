# تسليم جلسة — 2026-11-04 — `GOOG-006`: بناء `apps-script:sync` — سحب Apps Script خلف بوابة مراجعة

## المهمة والتفويض

- **طلب المالك (حرفي):** تسلسل أوامر — `npx @google/clasp login` («بحسابك، مرة واحدة») · `cd ~/celia-apps` · `npx @google/clasp clone <SCRIPT_ID>` («الجزء الطويل بعد /projects/ من رابط مشروعك») · `npm run apps-script:sync -- --pull` («شوف الفرق الأول») · `npm run apps-script:sync -- --pull --accept` («طبّق بعد ما تراجعه بس»).
- **التفسير المعتمد:** الأمران الأخيران لم يكونا موجودين في `package.json` — المهمة بناؤهما أداة حقيقية آمنة. الثلاثة الأولى خطوات مالك على جهازه بحسابه؛ لا ينفذها الوكيل ولا يدّعي تنفيذها.
- **معيار القبول:** معاينة لا تكتب شيئًا قبل `--accept`؛ تطبيق بعد المراجعة فقط؛ لا أسرار تُنسخ أو تُطبع؛ سحب فقط.
- **النطاق:** كود + اختبارات + وثائق + سجلات استمرارية. **لم يُنفَّذ:** لا `clasp login` · لا `clasp clone` · لا اتصال Google · لا نشر · لا مساس بأسرار · لا كتابة في `apps-script/` الحقيقي (العرض الحي كان على نسخة اصطناعية في `/tmp`).
