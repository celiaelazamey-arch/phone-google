# جلسة 2026-10-29 — MANUS-C1a: وسيط الخروج (egress proxy) قبل أي فتح للشبكة

**الفرع:** `arena/08fe16a0-phone-google` (منشأ من `main@acafa13` = دمج PR #93 بشجرة نظيفة).
**السلّم:** S4 (M-B) مكتمل؛ هذه أول شريحة في **S5 (M-C) — العينان**، وبالترتيب الذي تفرضه السياسة: **الباب قبل المفتاح**.
**معيار القبول المقاس:** طلب لمضيف خارج قائمة التشغيل = منع صريح قبل أي اتصال أو DNS؛ وطلب مسموح يُسجَّل بالدومين والحجم في سلسلة الأدلة.

## 1) لماذا C1 أولًا وماهيته

`src/agent/sandbox-policy.js:75` يرفض بالكود أي `network.mode !== 'deny'` وأي allowlist غير فارغة (`sandbox_egress_allowlist_backend_unavailable`). فتح الشبكة إذًا ليس تعديل إعداد بل أول ثغرة محتملة. لذلك نُفِّذ الوسيط **قبل** أي فتح، وبقي العزل مغلقًا حرفيًا.

## 2) ما نُفِّذ

1. **`src/agent/egress-proxy.js`** — وسيط HTTP(S) حقيقي:
   - **منحة لكل run** (`issueGrant({ runId, allowlist, ttlMs })`): رمز 64-hex معتم يُخزَّن بصمته فقط؛ المهمة لا ترى قائمة ولا مخزن رموز.
   - **قرار قبل DNS**: مطابقة نصية للـhost ضد قائمة التشغيل؛ المحجوب لا يصل إلى `http.request`/`net.connect` إطلاقًا.
   - **قائمة محدودة**: `host` (أي منفذ)، `host:port`، و`*.suffix` يطابق النطاقات الفرعية فقط؛ `*` وعناصر IDN والمعرّفات الملتبسة تُرفض بالبناء.
   - **HTTP absolute-form** و**CONNECT** فقط؛ بلا فك تشفير وبلا شهادة جذرية.
   - **تدقيق لكل قرار**: `{ runId, method, host, port, path (بلا query), decision, reason, status, bytesIn, bytesOut, durationMs }` — بلا ترويسات وبلا رموز.
   - **سقوف تقطع**: 1MiB طلب / 8MiB رد / 15s / 8 أنفاق لكل منحة، قابلة للضبط عند الإنشاء فقط.
   - `revokeRun`/`revokeGrant`/`activeGrants`/`events`/`stats`/`listen`/`close`.
2. **`createEvidenceEgressSink({ store })`** — صف أدلة واحد لكل قرار بالنوع الجديد `egress_request`، بـ`PASS` للسماح و`BLOCK` للمنع (أُضيف النوع في `src/agent/evidence.js` بشكل إضافي).
3. **لا مساس بـ`sandbox-policy.js`**: العزل ما زال `deny` وallowlist فارغة، وEP-11 يحرسان ذلك كاختبار دائم.

## 4) الحدود المعلنة

- **لا أداة ويب**: `web.fetch`/`web.search` = C2، ولم تُسجَّل أي أداة جديدة.
- **لا ربط في `createAgentHost`**: الوسيط وحدة قابلة للتركيب بلا مستهلك بعد؛ إضافته للإقلاع كانت ستنتج سطحًا ميتًا. الربط = C1-b.
- **لا فتح لشبكة العزل**: ما زال `deny`؛ ولا يُفتح قبل أن يصبح الوسيط هو المسار الوحيد (وفق الانحراف المقترح في [دليل الوسيط](../../agent-egress.md) §5).
- **لا قياس حي**: أي اتصال خارجي حقيقي قرار نشر منفصل.

## 6) الخطوة التالية

- **C1-b**: تركيب الوسيط في المضيف + منح لكل تشغيل + سقف زمني مرتبط بالتشغيل، **دون** فتح شبكة العزل.
- **C2**: `web.fetch`/`web.search` عبر الوسيط على المضيف، مع إسناد URL في الأدلة.
- **قرار قبل C2**: هل تبقى شبكة العزل `deny` دائمًا (المقترح) أم تُفتح لاحقًا؟ يُحسم بـDEC مستقل.
- **أول فحص آمن:** `node --test test/agent-egress-proxy.test.js` ثم `npm run check:continuity`.
