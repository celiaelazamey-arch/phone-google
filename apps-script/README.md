# apps-script/ — وجهة مزامنة Google Apps Script

هذا المجلد هو وجهة `npm run apps-script:sync -- --pull [--accept]` (GOOG-006 / DEC-142).

- كل مجلد فرعي هنا نسخة مرآة لمشروع clasp محلي من `~/celia-apps` (أو `CELIA_APPS_SCRIPTS_DIR`).
- **لا تحرّر الملفات هنا expecting أن تصل إلى Google** — الاتجاه سحب فقط. التعديل على Google يتم من مجلد النسخة المحلية عبر `clasp push` بقرار المالك.
- المعاينة (`--pull`) لا تكتب شيئًا؛ التطبيق يتطلب `--accept` بعد مراجعة الفرق.
- ملفات الاعتماد (`.clasprc.json` وغيرها) لا تُنسخ إلى هنا أبدًا، وأي محتوى يشبه سرًا يوقف المزامنة كلها.
- مشاريع موجودة هنا وغائبة عن المصدر تُذكر في التقرير (`missingFromSource`) ولا تُحذف تلقائيًا.
- هذا المستودع عام: ما يدخل هنا يصبح منشورًا. راجع [دليل المزامنة](../docs/apps-script-sync.md).
