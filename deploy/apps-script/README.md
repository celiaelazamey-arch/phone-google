# Google Apps Script — ما يضيفه فعلًا، وما لا يضيفه

ثلاثة سكربتات تُغني النظام عن اعتماد مدفوع أو يدوي، وتُقرأ لوحة حالة Google آليًا بدل لصقها.
كلها تعمل على **حساب Google المجاني**، بلا بطاقة وبلا خدمة إضافية على Render (الحصة 750 ساعة
تتشاركها خدمة واحدة فقط — انظر [`deploy/free-always-on`](../free-always-on/README.md)).

| الملف | يحلّ محلّ | النداء |
|---|---|---|
| `keepalive.gs` | **cron-job.org** (اعتماد خارجي بمفتاح API) | كل 10 دقائق |
| `deep-check.gs` | فحص يدوي عند الشك | يوميًا أو يدويًا |
| `status-relay.gs` | **لصق لوحة حالة Google** في المحادثات | كل ساعة |

## التزامن — كيف تصبح نسخة Drive ونسخة Git شيئًا واحدًا

المشكلة الحقيقية بعد اللصق ليست التركيب، بل **نسختان من الحقيقة**. أول تعديل في المحرّر يجعل
الاثنتين مختلفتين بلا أن يعرف أحد. لذلك هناك قفل وبوابة:

```bash
npm run apps-script:check                      # بوابة CI: تفشل عند أي انحراف
npm run apps-script:sync -- --push            # ادفع الملفات إلى المشروع (يحتاج clasp login)
npm run apps-script:sync -- --pull            # اسحب تعديل المحرّر، **ولا** تعتمده صامتًا
npm run apps-script:sync -- --pull --accept    # بعد مراجعة الفرق، ثبّت القفل
```

| الحالة | تُكتشف؟ |
|---|---|
| تعديل في محرّر Drive ثم `--check` | **نعم** — بصمة SHA-256 مختلفة |
| ملف جديد في المحرّر فقط | **نعم** — `unlocked` |
| ملف حُذف من Git وبقي في القفل | **نعم** — `missing` |
| إذن OAuth أوسع من الحاجة | **نعم** — `scope-too-broad` (مثل `drive` أو `mail.google.com`) |
| سرّ مدموج في نصّ يُدفع إلى Drive | **نعم** — `secret-pattern` |

`appsscript.json` يعلن **ثلاثة أذونات فقط**: `script.external_request` (نداء HTTP) · `script.send_mail`
(تنبيهات) · `script.scriptapp` (مُشغّلات). أي توسيع يُفشل البوابة.

**حدّ صريح:** `--push` و`--pull` يحتاجان `clasp login` بحسابك ووصولًا إلى `script.googleapis.com`؛
لا يعملان في بيئة الوكيل ولم يُختبرا هناك. **المقيس والمختبَر هنا هو القفل والانحراف** (`AS-09…AS-16`
بخمس طفرات)، لا الاتصال بـGoogle.

## التركيب — خمس دقائق

1. <https://script.google.com/home/all> ← **New project**.
2. الصق محتوى `keepalive.gs` (ويمكن لصق الثلاثة في مشروع واحد؛ أسماء الدوال لا تتعارض).
3. **Project Settings → Script properties**:
   | الخاصية | إلزامية | المعنى |
   |---|---|---|
   | `SERVICE_URL` | نعم | `https://<service>.onrender.com` بلا `/` في النهاية |
   | `ALERT_EMAIL` | للتنبيه | بريدك |
   | `SECRET_TOKEN` | لا | نفس `CELIA_MCP_API_TOKEN` إن كان `/readyz` يتطلبه |
   | `RELAY_SERVICES` | لا | قائمة مفصولة بفواصل؛ الافتراضي: Calendar · Drive · Gmail · Sheets · OAuth |
   | `ALERTS_ENABLED` | لا | `false` لإيقاف البريد مع إبقاء القياس |
4. شغّل `setup()` ← قبول الأذونات + مُشغّل كل 10 دقائق.
5. شغّل `checkOnce()` ← النتيجة في **Executions** وفي `LAST_STATE`.

للإيقاف الكامل: `teardown()` ← لا يبقى مُشغّل يستهلك حصتك.

## الحدود — مقيسة، لا مقدَّرة

| الحد | القيمة (حساب مجاني) | أثرها هنا |
|---|---|---|
| تنفيذ واحد | **6 دقائق** | كل دورة ثوانٍ؛ لا يُقترب منه |
| تشغيل المُشغّلات يوميًا | **90 دقيقة** | دورتنا ≈ 72 ثانية/يوم (0.13%) |
| نداءات UrlFetch | **20 000/يوم** | 144 نداء/يوم (0.7%) |
| مستلمو البريد | **100/يوم** | بريد واحد **عند تغيّر الحالة فقط** |
| مُشغّلات لكل مشروع | **20** | نستخدم 1–3 |

## حدود الصدق — ما لا يقوله هذا السكربت

- **ليس ضمان توفّر.** منعُ النوم يعني «الخدمة لا تنام لعدم وجود حركة»، ولا يعني «الخدمة متاحة».
  إن انقطعت Render أو انقطع حساب Google توقف النداء نفسه. لا يُستخدم في أي ادّعاء uptime.
- **`/readyz` = 503 ليس عطلًا شبكيًا.** الخدمة أجابت وقالت إنها **غير جاهزة**. السكربت يفرّق بين
  `not_ready` و`timeout` و`network_error`، لأن العلاج يختلف.
- **مرحّل حالة Google يقيس مزوّدًا خارجيًا**، لا نظامنا. «Google سليمة» لا تعني «نظامنا سليم».
- **فشل قراءة لوحة الحالة يُكتب `unknown`** ولا يُفسَّر «سليمًا».

## علاقته بالمستودع

- الاختبارات: `test/apps-script-keepalive.test.js` (`AS-01…AS-08`) — تتحقق من صحّة الصياغة، وأن
  كل `newTrigger` يشير إلى دالة موجودة، وأن **لا سرّ مدموج**، وأن التردد الموعود يساوي المنشأ.
- لا يُشغَّل Apps Script في CI (لا محاكي صادق لـ`UrlFetchApp`). الاختبار يغطي البنية لا التشغيل،
  وهذا مذكور صراحةً في أعلى ملف الاختبار.
- البند `OPS-004` (SLO/RPO/RTO) و`OPS-001` (metrics) يبقيان مفتوحين: هذا الملف يوفر **إشارة**،
  ولا يوفّر قياس SLO.
